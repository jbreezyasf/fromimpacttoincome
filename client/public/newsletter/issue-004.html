① Main Story

Anthropic Quietly Shipped Something Nobody Was Talking About

You can now run Claude Code and Claude Cowork against any model — GPT-5, Grok, Gemini, or your own local models. No announcement. No blog post. Just shipped.

This landed in the group chat without fanfare and it deserves a full explanation because most people read right past it. Anthropic added a configuration option inside Claude Desktop that lets you point the entire Claude Code and Cowork infrastructure at any model you want via OpenRouter as a gateway — or directly at a local model running on your own machine through Ollama. That means Claude's full agent harness — skills, MCP servers, file management, sub-agents — can now run against DeepSeek, Gemini, GPT-5, or whatever you have loaded locally. Nothing hitting an API. Nothing leaving your machine.

Here's how to set it up: In Claude Desktop, go to Menu → Developer → Configure Third-Party Inference. Set Connection to Gateway, then fill in: Gateway base URL as https://openrouter.ai/api, your OpenRouter API key, and auth scheme as x-api-key. OpenRouter has free models available right now — no $100-200/month subscription required to get started.

The bigger implication: if you're building for clients with sensitive data — healthcare, legal, finance — this changes the conversation entirely. You can now run the full Claude agent infrastructure locally with zero data leaving the building. That's not a workaround. That's a selling point worth real money.

  • OpenRouter = free starting point. Point Claude Desktop at OpenRouter and access multiple models without paying for each individually. Good for testing and comparison before committing to a deployment model.
  • Local inference = the privacy play. Running Ollama on your Mac with DeepSeek or another open model loaded means full Claude agent capability with complete data isolation. Perfect for sensitive client work.
  • This is not a workaround. It's a documented setting inside Claude Desktop. Anthropic built this. Use it.
💼 How does this apply to your business?

Any client in healthcare, legal, financial services, or government who pushed back on AI because of data privacy concerns just lost their main objection. You can now walk into those meetings and say the agent runs entirely on their infrastructure, nothing leaves their environment, and it still has the full capability of Claude's agent ecosystem. That's a different category of conversation — and a different price point.
