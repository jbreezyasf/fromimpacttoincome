① Main Story

Your End-of-Call Report: The Data Layer Every Agent Needs

If your voice agent is making calls but you have no record of what happened on them — you're flying blind. Here's the fix.

When your AI voice agent finishes a call, something needs to happen with that information. Who called? What did they say? Did the call succeed? Without capturing that data, every call is a black hole. The end-of-call report is how you pull everything out — transcript, call status, caller info, duration — and send it somewhere useful like a CRM, a Zapier workflow, or a Google Sheet.

Here's the exact JSON payload Derrick shared in the group — what your agent should send to a webhook after every call:

{
  "transcript": "",
  "call_id": "",
  "call_status": "",
  "duration": "",
  "start_time": "",
  "end_time": "",
  "agent_id": "",
  "customer_phone": "",
  "agent_phone": "",
  "name": "",
  "end_of_call_report": "",
  "email": "",
  "special_notes": ""
}

Each of those empty fields gets filled in automatically by Vapi when the call ends. The tool that sends this is called Bladetranscribe — it fires the payload to your webhook URL. In Zapier, you catch it with a Webhook trigger, then route the data wherever it needs to go. But here's the part that trips people up: you only want this to trigger on completed calls. That's where the filter comes in.

{
  "message": {
    "type": "end-of-call-report",
    "analysis": {
      "successEvaluation": "true"
    }
  }
}

Add this as a Filter step in Zapier right after your webhook trigger. It tells Zapier: only continue if this is an end-of-call-report AND the call was evaluated as successful. Everything else gets ignored. Clean data only.

  • No filter = chaos. Without it, your zap fires on every Vapi event — call started, ringing, ended, failed. Your CRM fills with garbage rows fast.
  • The transcript field is gold. Once you're capturing full transcripts, you can run them through AI to auto-generate follow-up emails, flag missed appointments, or score lead quality — all automatically.
  • Bladetranscribe is the messenger. It's a tool you configure inside your Vapi agent, not a separate app. It lives in the agent's tool settings and fires at call end.
💼 How does this apply to your business?

If you're building agents for clients — or using one yourself — this is your proof of work. Every call gets logged with a full transcript, timestamp, and outcome. Your client can see exactly what their AI said, when it said it, and whether it succeeded. "Here's a live dashboard of every call your agent handled last week" is a very different conversation than "trust me, it's working." That's not just useful — that's a selling point worth thousands a month.

② Also This Week

Vapi Tool Setup: Start With Filter, Not Create

Several members hit the same wall this week trying to set up custom tools in Vapi. The common mistake: going straight to "Create Tool" without first using the Filter option. When you skip the filter, your end-of-call logic misfires — the tool triggers on every event instead of just the ones you want.

The right path: Tools → Filter → set your conditions first. Once the filter is in place, your tool only activates when the exact message type and success criteria you define are met. Derrick's one-word answer when multiple members asked where to go: "Filter." That's it. Start there.

If you've already built your tools without the filter and things aren't behaving right — go back and add it. It's not a workaround, it's how the system is supposed to be structured.

③ Worth Knowing

ElevenLabs Platform Choice Matters More Than You Think

When setting up your voice in Vapi, you're asked to choose a platform inside ElevenLabs. The correct choice is Agents Platform — not Creative Platform. Creative is built for standalone projects and one-off audio generation. Agents is built specifically for integrations like Vapi. Choose wrong and your voice setup breaks in ways that are genuinely confusing to debug because everything looks fine on the ElevenLabs side.

This came up multiple times in the bootcamp group. If your voice agent isn't behaving as expected and you set up ElevenLabs recently, check which platform you selected first. It's a five-second fix if you catch it early.
